## 4주차 반응형 수정

### 확인할 문제
작은 화면에서 메뉴,기능 카드, 이메일 폼이 좁여보였다.

### 수정한 내용
- viewport 메타 태그를 추가했다.
- 콘텐츠와 width와 max-width를 함께 사용했다.
- 기능 카드 목록을 반응형 Grid로 변경했다.
- 768px 이하에서는 메뉴, 카드, 폼을 한 열로 구성했다.

### 확인할 화면 너비
1100px/ 769px / 768px/ 390px



# 6주차 실습
다크 테마 버튼을 클릭하면 화면 테마가 변경됩니다.
닉네임을 입력하면 입력한 글자 수가 실시간으로 표시되고 10글자에서막힙니다.
동의 체크박스를 선택하면 안내 문구가 변경되고 시작 버튼이 활성화됩니다.
탭 전환: 할일 추가, 할일 완료, 마감시한 설정 탭을 선택하면 해당 기능의 설명이 표시됩니다.
화면을 줄여도 모든화면테스트에서 잘 적용됩니다.

# 7주차 실습

## 사용자목표
-사용자: 매일 할일을기록하고 관리하는사람
-목표: 할일을 기록하고 마감날짜를설정한뒤 입력한내용을 확인한다

## 사용자의 흐름
1. Daily 활용에 동의하고 'Daily 설정 시작하기'를 누른다.
2. 할일 내용을 입력하고 마감 시한설정하기를 누른다
3. 마감날짜를 선택하고 설정확인하기를누른다
4. 설정 완료 안내를 확인하고, 필요하면 다시설정한다.



## 인터렉션 시나리오
1. 시작과 Daily 활용 안내
-행동, 이벤트: 기존 동의 체크박스를 선택하고 'Daily 설정 시작하기'를 클릭한다.
-조건: 이용 동의가 선택되었는가?
-반응,다음 상태: 동의전에는 버튼을 누를 수없다. 동의후 클릭하면 사용 목적에 설명하는 안내 팝업이 열린다.
                팝업에서 '돌아가기'를 누르거나 ESC를 누르면 동의를 해제하고 시작화면에 남는다.
                '동의하고 설정 시작하기'를 누르면 할일 입력 화면을 연다.


2. 할일 입력
- 행동, 이벤트: 할일 내용을 적고 '마감 시한 선택하기'를 클릭한다
-조건: 앞뒤 공백을 지운 입력값이 비어있는가?
- 반응, 다음상태 : 비어있으면 같은화면에오류를 표시하고 입력창에 초점을 둔다.
                값이 있으면 저장하고 마감시한 선택으로 이동한다..

3. 마감날짜 선택
- 행동, 이벤트: 필요하면 마감날짜를 선택하고 '내용 확인하기'를클릭한다
- 조건: 마감날자를 선택했는가?
-반응, 다음 상태: 날짜를선택하면 해당날짜를 저장 미선택시 빈칸으로 표시

4. 내용 확인
- 행동, 이벤트: 할일 내용과 마감날짜를 확인후 '수정하기'또는 설정 완료하기'를클릭한다
- 조건: 수정인가, 완료인가?
- 반응, 다음상태 : 수정하면 기본 값을 유지하고 조건 선택으로 돌아간다.
                완료하면 완료 안내로 이동한다.

5. 완료와 다시 설정
- 행동, 이벤트: 완료 안내를 열고 필요하면 '다시 설정하기'를 클릭한다.
- 반응, 다음 상태: 다시 설정할시 마감 날짜 할일 내용 등을 초기화하고 입력단계부터 다시시작한다.


## 시험

## 새로추가한기능 : 7주차에서추가한 Daily설정내용의 정리한 '할일 보기'기능을 추가했다.

1. 할일 목록열기
- 행동, 이벤트: '할일 보기' 버튼을 클릭한다.
- 조건: 목록패널이 숨겨져있는가?
- 반응, 다음상태: 숨겨져있으면 날짜선택달력을 열고 버튼 문구를 '할일 숨기기'로 바꾼다.
                열려있으면 패널을 닫고 '할일 보기'로 되돌린다

2. 날짜 선택
- 행동, 이벤트: 달력에서 날자를 선택한다
- 조건: 날짜를 선택했는가? 선택한날짜에 할일이있는가?
- 반응, 다음상태: 있다면 할일이 목록으로표시되고 없다면 '이 날짜에 등록된 기록이 없습니다.' 가 입련된다

3. 완료 체크
- 행동, 이벤트: 할일앞의 체크박스를 클릭한다
- 조건: 체크박스가 체크되었는가?
- 반응, 다음상태: 체크가되었다면 완료상태저장하고 글자에취소선이생긴다. 채크해제를 눌른다면 완료상태를 해제하고 취소선을없앤다. 다른날짜를보고돌와와도 유지가된다


## 테스트 결과
- 할일과 마감날짜를 등록한뒤 '할일 보기'에서 날짜를선택시 등록된할일이표시됨
- 등록되지않은날짜를선택시 '이 날짜에 등록된 기록이 없습니다'가 표시됨
- 체크박스클릭시 완료상태가되면서 글자에취소선이생김
- 날짜선택삭제시 안내문구가표시되지않음
- 체크후 다른날짜선택하고 다시돌아와도 유지됨
- '할일 숨기기'클릭시 패널이 닫히고 버튼문구가 '할일 보기'로바뀜
